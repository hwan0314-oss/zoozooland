# 🦁 쥬쥬랜드 안내지도

관리자 페이지를 통해 지도상의 시설 위치와 정보를 쉽게 관리할 수 있습니다.

## 🚀 서버 실행 방법

### 1. Node.js 설치 확인
```bash
node --version
```
Node.js가 설치되어 있지 않다면 [nodejs.org](https://nodejs.org)에서 설치하세요.

### 2. 의존성 설치 (최초 1회만)
```bash
npm install
```

### 3. 서버 실행
```bash
npm start
```

서버가 실행되면:
- 사용자 페이지: http://localhost:3000/index.html
- 관리자 페이지: http://localhost:3000/admin.html

## 📝 관리자 페이지 사용법

### 자동 저장 모드 (서버 실행 중)
1. `npm start`로 서버 실행
2. http://localhost:3000/admin.html 접속
3. 좌측 ◀ 버튼으로 사이드바 숨기기
4. 지도에서 마커를 **드래그**하여 위치 이동
   - 드래그하면 **자동으로 index.html에 저장됨**
5. 시설 클릭 → 정보 편집 → "💾 저장" 클릭
   - 저장 시 **자동으로 index.html에 반영됨**
6. 사용자 페이지 새로고침으로 확인

### 수동 저장 모드 (서버 미실행)
1. admin.html을 브라우저로 직접 열기
2. 위치 수정 및 정보 편집
3. 하단 "복사" 버튼 클릭
4. VS Code 등 에디터로 `index.html` 열기
5. `const FACILITIES = [` 부분을 찾아 전체 배열 교체
6. 저장 후 브라우저 새로고침

## 🔧 주요 기능

### 사용자 페이지 (index.html)
- 위성 지도 + 시설 마커
- 하단 시트: 시설 목록 및 상세 정보
- GPS 내 위치 표시
- 건물 일러스트 오버레이

### 관리자 페이지 (admin.html)
- ✅ 마커 드래그로 위치 수정
- ✅ 시설 정보 편집 (이름, 아이콘, 카테고리 등)
- ✅ 편의시설 체크 (화장실, 카페, 수유실)
- ✅ 새 시설 추가 (버튼 또는 지도 더블클릭)
- ✅ 시설 삭제
- ✅ **자동 저장** (서버 실행 시)
- ✅ JSON 내보내기/가져오기 (백업용)

## 💡 팁

- **사이드바 가림 문제**: 좌측 ◀ 버튼으로 숨기세요
- **변경사항 확인**: 사용자 페이지 새로고침 (Ctrl+R)
- **서버 종료**: 터미널에서 Ctrl+C

## 🐛 문제 해결

### "서버 미실행" 경고가 뜨는 경우
```bash
# 터미널에서 실행
npm start
```

### 포트 3000이 이미 사용 중인 경우
`server.js` 파일에서 PORT 번호를 변경하세요:
```javascript
const PORT = 3001; // 다른 포트로 변경
```
