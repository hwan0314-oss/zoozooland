> 현재 상태: **2026 겨울 시즌 방향 선택 대기** (2026-10-24 기준 그대로). 선택되면 아래 "시즌 테마" 표를 채우고 그 값을 기준으로 작업한다.

## 브랜드 고정 요소 (시즌과 무관하게 유지)
- 로고/약칭: **ZZL** (= 즐). 워드마크는 굵은 산세리프, 자간 좁게.
- 브랜드 포인트 컬러: **ZZL 라임 `#D4FF00`** — 어느 시즌이든 CTA·강조 한 곳 이상에 남긴다.
- 말투: "ZZL겨볼까?", "ZZL거운", "쥬민(동물)" 같은 ZZL 말장난. 반말·친근체, 과장 광고 문구 금지.
- 대상: 아이 동반 가족이 1순위. 한국어 문구가 주, 영어 문구는 장식(작은 라벨)으로만.

## 레이아웃 규칙
- 기준 폭: 데스크톱 1440px, 모바일 390px. 두 폭 모두 가로 스크롤 없을 것.
- 콘텐츠 최대 폭 1200px, 좌우 여백 모바일 20px / 데스크톱 48px.
- 첫 화면(모바일 기준 스크롤 없이)에 **예약 버튼 + 오늘 운영 여부/시간**이 보여야 한다.
- 섹션 순서 원칙: 예약·요금 → 오늘의 프로그램 → 즐기는 법(지도/도감) → 후기·인스타 → 오시는 길 → 단체·제휴.
- 현재 메인 섹션 순서(2026-11 모바일 UX 1차): 히어로 → 입장권·이용안내(요금·먹이체험·공연·이용수칙) → 인스타그램 → 리뷰 → 네이버 예약 혜택 → 공지 → 가이드맵 → FAQ → 오시는 길 → 단체·제휴. 방문 결정에 필요한 가격·시간을 분위기(인스타)보다 먼저 둔다.
- 모바일 내비게이션(767px 이하): 왼쪽 ZZL 로고, 오른쪽 「메뉴」 버튼 하나. 메뉴는 내비 바로 아래 펼치는 패널로, 항목은 입장권·체험 / 가이드맵 / 자주 묻는 질문 / 오시는 길 / 단체 예약, 맨 아래에 라임 「네이버 예약하기」(개인 예약이 가장 눈에 띄게). 항목 높이 52px 이상(터치 44px 이상), 각진 사각형·검정 바탕·라임 유지. PC 내비게이션은 그대로.
- 새 링크·버튼에도 `data-track`·`data-cta`를 붙여 위치별 클릭을 구분한다(모바일 메뉴: `menu_click`, `booking_click`·`group_booking_click` + `data-cta="mobile_menu…"`).

## 이미지 규칙
- 웹용 WebP, 긴 변 1600px 이하, 1장 300KB 이하 목표.
- `build.py`가 `index.html`의 `images/*.jpg|png`를 폭 320·480·640·1280·1920 WebP로 자동 변환한다(원본보다 큰 폭은 만들지 않음). 작게 보이는 이미지는 `data-sizes`(예: 인스타 `33vw`)로 표시 폭을 알려 줘야 작은 파일이 선택된다.

## 글꼴 불러오기 규칙 (성능)
- Google Fonts는 렌더링을 막지 않게 불러온다(`preload` + `media="print" onload`, `display=swap`). 첫 방문에서 잠깐 시스템 글꼴로 보였다가 바뀔 수 있다.
- 불러오는 굵기는 실제로 쓰는 것만: Inter 400·700·900 / JetBrains Mono 500 / Noto Sans KR 500·900. 새 굵기를 쓰려면 `index.html` `<head>`의 글꼴 주소 세 곳에 함께 추가한다.
- 동물 사진은 실제 쥬쥬랜드 촬영본 사용 (스톡 이미지 금지).
- 대체텍스트(alt)는 "알파카 '○○'가 먹이를 먹는 모습"처럼 구체적으로.
