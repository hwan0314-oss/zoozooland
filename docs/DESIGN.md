## 브랜드 고정 요소 (시즌과 무관하게 유지)
- 로고/약칭: **ZZL** (= 즐). 워드마크는 굵은 산세리프, 자간 좁게.
- 브랜드 포인트 컬러: **ZZL 라임 `#D4FF00`** — 어느 시즌이든 CTA·강조 한 곳 이상에 남긴다.
- 말투: "ZZL겨볼까?", "ZZL거운", "쥬민(동물)" 같은 ZZL 말장난. 반말·친근체, 과장 광고 문구 금지.
- 대상: 아이 동반 가족이 1순위. 한국어 문구가 주, 영어 문구는 장식(작은 라벨)으로만.

## 시즌 캐릭터 (히어로 영상)
- 캐릭터: 3D 프레리독, 두 발로 선 망보기 자세 + 팔짱, 무심한 표정. **웃지 않고, 만화풍이 아닌 실사 털 질감.** 옷은 라임(#D4FF00) 패딩 + 검정 버킷햇 + 작은 선글라스. 옷·화면에 글자나 로고 없음.
- 계절마다 옷만 바꾼다(봄 바람막이·여름 반팔 등). 같은 캐릭터를 릴스·굿즈에도 쓴다.
- 구도: 16:9, 캐릭터는 오른쪽 1/3, 왼쪽은 비운 어두운 배경. 모바일은 같은 영상에서 캐릭터 부분을 세로로 잘라 쓴다.
- 영상: 5초, 첫·끝 프레임을 같은 이미지로(키프레임) 만들어 끊김 없이 반복. **소리 없음, H.264 mp4, 1개 1MB 이하.** 생성 도구의 표식이 없는 유료 결과물만 쓴다.
- 파일: `website/images/hero/prairie.mp4`(PC)·`prairie-m.mp4`(모바일)와 같은 이름의 `.webp`(첫 장면, 영상 전·움직임 줄이기 때 보임). 계절이 바뀌면 이 4개만 바꾼다.
- 배치: PC는 캐릭터가 오른쪽 70%, 글은 왼쪽. 모바일은 캐릭터 오른쪽 위, 제목은 그 왼쪽 아래, 운영 상태·예약 버튼은 첫 화면 안.
- 시즌 효과: `settings.json`의 `season_effect` — 겨울은 `"winter_snow"`(눈), 가을은 `"autumn_leaves"`.

## 레이아웃 규칙
- 기준 폭: 데스크톱 1440px, 모바일 390px. 두 폭 모두 가로 스크롤 없을 것.
- 콘텐츠 최대 폭 1200px, 좌우 여백 모바일 20px / 데스크톱 48px.
- 첫 화면(모바일 기준 스크롤 없이)에 **예약 버튼 + 오늘 운영 여부/시간**이 보여야 한다.
- 섹션 순서 원칙: 예약·요금 → 오늘의 프로그램 → 즐기는 법(지도/도감) → 후기·인스타 → 오시는 길 → 단체·제휴.

## 이미지 규칙
- 웹용 WebP, 긴 변 1600px 이하, 1장 300KB 이하 목표.
- 동물 사진은 실제 쥬쥬랜드 촬영본 사용 (스톡 이미지 금지).
- 대체텍스트(alt)는 "알파카 '○○'가 먹이를 먹는 모습"처럼 구체적으로.
