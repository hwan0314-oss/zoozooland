> 현재 상태: **2026 겨울 시즌 방향 선택 대기.** 선택되면 아래 "시즌 테마" 표를 채우고 그 값을 기준으로 작업한다.

## 브랜드 고정 요소 (시즌과 무관하게 유지)
- 로고/약칭: **ZZL** (= 즐). 워드마크는 굵은 산세리프, 자간 좁게.
- 브랜드 포인트 컬러: **ZZL 라임 `#D4FF00`** — 어느 시즌이든 CTA·강조 한 곳 이상에 남긴다.
- 말투: "ZZL겨볼까?", "ZZL거운", "쥬민(동물)" 같은 ZZL 말장난. 반말·친근체, 과장 광고 문구 금지.
- 대상: 아이 동반 가족이 1순위. 한국어 문구가 주, 영어 문구는 장식(작은 라벨)으로만.

## 레이아웃 규칙
- 기준 폭: 데스크톱 1440px, 모바일 390px. 두 폭 모두 가로 스크롤 없을 것.
- 콘텐츠 최대 폭 1200px, 좌우 여백 모바일 20px / 데스크톱 48px.
- 첫 화면(모바일 기준 스크롤 없이)에 **예약 버튼 + 오늘 운영 여부/시간**이 보여야 한다.
- 섹션 순서 원칙: 예약·요금 → 오늘의 프로그램 → 즐기는 법(지도/도감) → 후기·인스타 → 오시는 길 → 단체·제휴.

## 이미지 규칙
- 웹용 WebP, 긴 변 1600px 이하, 1장 300KB 이하 목표.
- 동물 사진은 실제 쥬쥬랜드 촬영본 사용 (스톡 이미지 금지).
- 대체텍스트(alt)는 "알파카 '○○'가 먹이를 먹는 모습"처럼 구체적으로.
